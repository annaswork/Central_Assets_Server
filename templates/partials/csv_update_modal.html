How it works:
  • Your CSV must contain a name column to match existing records.
  • If an asset name contains commas, wrap it in double quotes: "Art Nouveau, Bedroom Edition".
  • For multiple tags or list fields, wrap in quotes: "Vintage, Stylish, Retro" or separate with semicolons.
  • All other columns will update the matching item's data attributes.
  • If an active filter is applied on this page, only items matching the filter will be updated.
