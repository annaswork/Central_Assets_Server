0. How the Server Works: Central Library vs. Your App Instances

The platform keeps one shared Central Data Catalog and isolated App Instance Working Sets (one per mobile/web app, such as Collage Maker or Photo Editor). Understanding what stays app-only versus what pushes to Central prevents mistakes:

Action in Manager Portal Where Change Is Saved Affects Central Data or Other Apps?
Browse Categories, Subcategories, Assets Read-only view of Central Catalog No (read-only)
Toggle Enabled, Premium, Rewarded, Credited, Credits, Sequence, Tags Your App Instance only (instance_*) No — strictly isolated per app
✏️ Edit / Rename Folder or Asset / Interactive Frame Editor Your App Instance overrides{} (+ isolated media in instance_overrides/<app_id>/) No — central data stays unchanged; asset edits notify Admin so Admin can optionally adopt them
Create Category/Subcategory or Upload new Asset inside an App Instance Central Catalog + automatically linked into your App Instance Yes (additive only) — pushes into existing matching Central folders or creates them cleanly
Detach Folder / Detach / Remove inside an App Instance Soft-deletes only the reference inside your App Instance No — Central folders & uploaded assets remain safe and cannot be deleted by managers

📖 1. Reading Server Data

1.1 Browsing the Central Library (Read-Only)

  • Use the sidebar links under Central Data (Read-Only): Super Categories, Categories, Subcategories, and Assets.
  • Filter assets by Category, Subcategory, Media Type (Images, Videos, Audios, JSON, Frames, HTML, Files / Docs), keyword search, and page size (20–200).
  • Click any asset to open the Preview Modal (View More Fields) to inspect attached media blocks, frame bounding-box overlays, or sandboxed HTML previews.

1.2 Viewing App Instances & Requesting Access

  • Open App Instances to see every app you own or were granted access to, including its unique instanceId and package_name.
  • Need access to an existing app? Submit an access request on the App Instances page with optional operator notes for Super Admin approval.
  • Need a brand-new App Instance? Submit a creation request (Name + Package Name); once approved by Admin, it appears automatically in your workspace.

1.3 Reading Scoped Analytics & API Keys (Including Shared Admin Keys)

  • Scoped Analytics (Analytics): Monitor impressions, downloads, request bandwidth, endpoint hit metrics, and client errors filtered strictly to your accessible App Instances.
  • API Keys (API Keys): You see all API keys bound to your accessible App Instances — both keys you generated and keys created by an Admin for that app (🛡️ Issued by Admin). Unscoped global Admin keys remain hidden.
  • Viewing the Full Secret Key via 2FA: Click 🔑 View Key on any listed key and enter your 6-digit TOTP Authenticator code (or backup code) to decrypt and copy the full ak_... key. Enable 2FA first under Settings if not configured yet.
  • Editing Limits: Click ⚙️ Limits on either your own key or an Admin-created key for your accessible app to adjust Layer 1 (User IP Limit req/min) and Layer 2 (App Surge Ceiling req/min). (Only the key creator can Revoke or Delete a key.)

✍️ 2. Writing Data: Folders, Uploads, App Edits & Safe Detach

2.1 Organizing Folders & Importing Central Content

  • Create Folders: Inside an App Instance (Content → Folders Tab), click + New Folder / Sub-folder or + Add Sub-folder to create a Category, Subcategory, or app-local Super Category. New Categories/Subcategories auto-sync with Central Library (reusing existing folders if already present or creating them cleanly).
  • Smart Content Picker (📥 Import Central Data): Clicking 📥 Import Central Data on a Category card automatically opens the picker on the Subcategories tab targeting that Category. Clicking 📥 Import on a Sub-folder card opens the Assets tab targeting that Sub-folder. Imported assets link by reference with zero file duplication.
  • Reordering, Super-Grouping & Tags: Drag the ⠿ handle on Category cards, Sub-folder cards, or Asset table rows to update client sequence (#1, #2...). Assign Categories to a Super Category via the dropdown in each Category toolbar, manage reusable app tag bubbles, or click 🏷️ Tags individually/in bulk.

2.2 Direct Uploading from an App Instance (Auto-Pushed to Central)

Managers can upload creative assets directly inside any accessible App Instance using two dedicated workflows (accessible from the app header, Category card, Sub-folder card, or Assets tab):

⚡ Bulk Single-File Add
Fast Multi-File Upload & Grouping
  • Drop many images, videos, audios, SVGs, Lottie JSONs, HTML, XML/docs, or frames at once.
  • Rename custom Block Keys (e.g. background, overlay) or toggle Auto-Separate Block Keys.
  • Check Group Files With Same Asset Name to bundle multiple files into a single multi-block asset.
  • Duplicate & visual similarity checks guard against accidental re-uploads (409 protection).
🖼️ + Multi-File Asset
Structured Asset + Frame & Crop Tools
  • Combine named blocks (image, video, audio, json, frames, html, file) plus custom thumbnails and descriptions.
  • Use non-destructive built-in cropping that preserves alpha transparency (no black/white background fills on PNG/WebP/GIF).
  • Use OpenCV Frame Placeholder Detection on transparent PNG frames to auto-extract slot boxes.
🔄 Automatic Central Sync: Anything you upload directly inside an App Instance is pushed to the Central Library (into matching existing Categories/Subcategories or creating new ones automatically) and linked straight into your app. Once uploaded to Central, it cannot be deleted by managers.

2.3 App-Level Editing, Interactive Frame Editor & Admin Proposals

  • Folder Editing (✏️ Edit / Rename): Change a Category or Sub-folder's name, thumbnail_url, or image_url at the app level. Central Library names/images remain intact.
  • Asset Editing (✏️ Edit) & Interactive Frame Editor: Customize an asset's display name, description, thumbnail, more_fields blocks, or fine-tune transparent frame coordinates/rotation/elevation interactively on the canvas (/frames). Newly uploaded replacement files during editing are stored isolated inside instance_overrides/<app_id>/.
  • Admin Review Workflow: Every app-level Asset edit or Frame Editor save automatically sends a structured asset_update change summary to Admin (Messages) so Admin can review the diff and either update Central Data or leave it app-only.
  • Quick Propose (💡 Propose Central Data): Send central folder/asset requests or feedback directly to Super Admin operators.

2.4 Detaching vs. Deleting (Central Data Is Protected)

Clicking Detach Folder, Detach, or Remove inside an App Instance only detaches that folder or asset from that specific app (detaching a Category also detaches its child sub-folders and assets in that app). Central assets and other App Instances are never deleted or modified.

🗂️ 3. Accessing Files & Media Delivery

3.1 How File & Endpoint Authentication Works

All creative assets stored under /static/central_data/... and /static/instance_overrides/... are access-controlled. Direct anonymous HTTP requests without authentication return 401 Unauthorized.

Client Context Authentication Method Example
Manager Portal in browser Signed session cookie (manager_session) Automatic while logged in (previews, frame editor, sandboxed HTML)
Mobile / Backend REST Client HTTP Header X-API-Key (preferred) X-API-Key: ak_prod_...
Image/Video Tags & Browser URL Bar Query Param api_key / apiKey / key /static/central_data/.../frame.png?api_key=ak_prod_...
Standard Bearer HTTP Client Authorization Header Authorization: Bearer ak_prod_...

3.2 Reading File URLs from API Responses & Recording Usage Events

  • Catalog & Asset Endpoints: Fetch your app hierarchy in one call with GET /api/v1/instance/{instanceId}/catalog or paginate/filter via /super-categories, /categories, /subcategories, and /assets (supports only_enabled=true, sort, order, tag).
  • File URLs inside Assets: Use thumbnail_url for previews and more_fields.blocks for actual media (image, video, audio, json, html, file, *_list arrays with items[], and frames with url + coordinates[]). Prepend your server origin to relative /static/... paths and attach the API key.
  • Analytics Tracking: Fire POST /api/v1/instance/{instanceId}/assets/{assetId}/track with {"event": "view"} when previewed and {"event": "download"} when applied/exported. Visit API Usage Method for ready-to-copy cURL commands and Kotlin examples.

⭐ 4. Setting Data Free, Premium, Rewarded & Credited (All 5 Ways)

Every App Instance controls its own monetization flags independently of Central Data. Each item resolved by the client API carries is_enabled, is_premium, is_rewarded, is_priced, and rewarded_credits. You can configure these tiers in five ways depending on whether you want individual precision or app-wide automation:

Way 1 · Folder Cards
Single-Folder Checkboxes (Folders Tab)

Directly toggle the Premium or Rewarded checkboxes on folder cards. Changes save immediately and display PREMIUM / REWARDED pills:

  • Super Category: Premium checkbox
  • Category Folder: Premium checkbox (and distribution tools for its child Sub-folders)
  • Sub-folder Card: Both Premium and Rewarded checkboxes
Way 2 · Asset List Table
Inline Row Toggles, Credited & Credits

Open Content → Assets Tab → List View to edit each asset row inline:

  • Enabled: Show/hide the asset in the client app API.
  • Premium (is_premium): Mark for paid/pro subscription.
  • Rewarded (is_rewarded): Unlock via rewarded ad.
  • Priced / Credited (is_priced): Enables the numeric Credits column (defaults to 5 credits; editable per asset).
Way 3 · Preview Modal
Asset Preview → INSTANCE SETTINGS

In either List View or Blocks View, click any asset card or thumbnail to open the Preview Modal, then toggle Enabled, Premium, Rewarded, Credited, or enter Credits inside the INSTANCE SETTINGS table.

Way 4 · Multi-Select & Swipe
Bulk Asset Selection Toolbar

Select multiple assets in List View (checkboxes / Select All) or in Blocks View (click or click-and-drag swipe across card topbars). From the floating bulk toolbar, click:

Enable · Disable · Premium · Normal · Set Rewarded · Remove Rewarded

Way 5 · Automated Tier & Frequency Distribution Engine (⚡)

For fast, repeatable monetization patterns across dozens or hundreds of items, use the ⚡ Tier Distribution modal from any of these 5 entry points:

Button Location What It Updates Count Mode Options
1. Folders Tab Header
⚡ Distribute All Sub-folders' Assets		 Assets inside every non-empty Sub-folder in the entire App Instance Fixed Count or Percentage (%) per sub-folder
2. Category Card Header
⚡ Distribute Tiers		 The Sub-folders belonging to that Category Exact counts against total sub-folders in Category

Understanding Tier Distribution Rules & Frequency Patterns

  • N - 1 Free Preservation Guarantee: Out of N items in any scope, combined Premium + Rewarded cannot exceed N - 1, ensuring at least 1 item always remains Free / Normal (for 1-item folders, max paid items is 0; empty folders are skipped in bulk runs).
  • Fixed Count vs. Percentage (%) in Bulk Mode: In Fixed Count mode, smaller sub-folders clamp proportionally down to N - 1 automatically. In Percentage (%) mode, each sub-folder receives proportional rounded counts based on its size (combined Premium % + Rewarded % must stay strictly below 100%).
  • Sequential Batch Frequencies: Items are assigned in display sequence order using your batch sizes (Free/Normal Batch, Premium Batch, Rewarded Batch). Setting asset-level Rewarded via distribution also initializes rewarded_credits = 5 if not already set.
  • Combined vs. Alternating Paid (🔁 Alternate): Check the Live Sequence Preview inside the modal before clicking ⚡ Apply Distribution. Every container remembers its last settings cleanly!
Example Sequences (10 Items · 2 Premium · 2 Rewarded):
Combined Mode (Normal=3, Premium=1, Rewarded=1, Alternate OFF): Free → Premium → Rewarded per cycle
#1 Free #2 Free #3 Free #4 Premium #5 Rewarded #6 Free #7 Free #8 Free #9 Premium #10 Rewarded
Alternating Paid Mode (Normal=2, Premium=1, Rewarded=1, Alternate ON): Free → Premium → Free → Rewarded
#1 Free #2 Free #3 Premium #4 Free #5 Free #6 Rewarded #7 Free #8 Free #9 Premium #10 Free

🛟 5. Key Rules & Quick Troubleshooting

  • "View Key tells me to enable 2FA": Enable Two-Factor Authentication in Settings (/manager/settings/2fa/setup). Both TOTP 6-digit codes and your generated backup codes unlock secret key reveal.
  • "I see an Admin-created key without a Delete or Revoke button": Managers with access to an app can view Admin-created keys for that app, edit their IP/Surge rate limits, and reveal the key via 2FA—only the creator can revoke or delete a key.
  • "Mobile app gets 401/403 on JSON or Image URLs": Confirm the X-API-Key header (or ?api_key=ak_... query param on image/video URLs) matches an active key bound to that exact instanceId with categories:read and assets:read scopes.
  • "Distribute says No assets found": Empty sub-folders have 0 assets; import or upload at least 2 items first so the N - 1 rule can mark items Premium/Rewarded while leaving at least 1 Free item.
  • "I want to revert an app-level override back to Central": Open the folder/asset edit dialog and use Reset Overrides to restore live Central titles, thumbnails, and media blocks for that App Instance.
