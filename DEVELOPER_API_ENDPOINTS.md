# 📱 Client API & Endpoints Specification for Developers

> **Document Type:** Developer Hand-off Specification  
> **Audience:** Mobile (Android / iOS) & Web Frontend Developers  
> **Server Base URL Example:** `https://assets.yourcompany.com/api/v1`

---

## 1. Credentials Provided by Manager

To integrate creative assets into your app or web frontend, your Manager will provide **three values**:

| Setting | Location / Header | Example Value | Description |
| :--- | :--- | :--- | :--- |
| **Base URL** | Prefix | `https://assets.yourcompany.com/api/v1` | Server root API endpoint |
| **App Instance ID** | Path variable `{instanceId}` | `6650a3f1c2e4b80012abcdef` | 24-character hex ID isolating your app's content |
| **API Key** | Header `X-API-Key` | `ak_prod_aBcDeFgHiJkLmNo...` | Secret key authenticating requests |

### Required HTTP Headers

Every request from the client app must include the following header:

```http
X-API-Key: ak_prod_aBcDeFgHiJkLmNoPqRsTuV_xYzAbCdEfGhIjKlMnOpQrStUvWx
```

> **Note on Scopes:** The API key generated by the Manager requires read scopes: `categories:read` and `assets:read`.

### Dual-Layer Rate Limiting

The API implements a dual-layer rate limiting strategy:

1. **Layer 1: Per-Client IP Rate Limit (`user_ip_limit`)**
   - **Default:** 60 requests / minute per client IP address.
   - Configurable per app key by Manager or Admin.
   - Prevents an individual malicious or misconfigured device from exhausting app quotas.
2. **Layer 2: App-Wide Surge Ceiling (`app_surge_ceiling`)**
   - **Default:** 10,000 requests / minute across all clients combined.
   - Configurable per app key by Manager or Admin.
   - Protects the central backend database and storage infrastructure during massive global traffic surges.

#### Rate Limit Response Headers (on HTTP 429)

When rate limits are exceeded, the server responds with HTTP `429 Too Many Requests` and headers:

```http
HTTP/1.1 429 Too Many Requests
Content-Type: application/json
Retry-After: 60
X-RateLimit-Limit-User: 60
X-RateLimit-Limit-App: 10000
X-RateLimit-Violation: user_ip_limit
```

Response JSON body:
```json
{
  "error": "Too Many Requests",
  "detail": "Client IP rate limit exceeded (60 requests/minute). Please slow down.",
  "layer": "user_ip_limit",
  "retry_after_seconds": 60
}
```

## 2. Media URL Resolution

All image, thumbnail, and media file URLs returned by the API are **root-relative paths** (e.g. `/static/central_data/stickers/summer/sun.png`).

To load these files in an image loader (like Glide, Coil, Kingfisher, or an HTML `<img>` tag):
```text
Full URL = <SERVER_ORIGIN> + <RELATIVE_URL>
Example:  https://assets.yourcompany.com + /static/central_data/stickers/summer/sun.png
```

### 3.2 List Categories

Fetches the list of categories assigned to this app instance.

* **Method:** `GET`
* **Path:** `/api/v1/instance/{instanceId}/categories`
* **Required Scope:** `categories:read`

#### Query Parameters
| Parameter | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `only_enabled` | `boolean` | No | `false` | If `true`, returns only enabled categories. |

* **Request Body:** None

#### Response (`200 OK`)
```json
[
  {
    "id": "66a1b2c3d4e5f60012345678",
    "sourceId": "669f1234abcd5678ef901234",
    "name": "Stickers",
    "thumbnail_url": "/static/central_data/stickers/thumb.webp",
    "image_url": "/static/central_data/stickers/banner.webp",
    "is_enabled": true,
    "sequence": 1,
    "overrides": {}
  }
]
```

#### cURL Example
```bash
curl -X GET "https://assets.yourcompany.com/api/v1/instance/6650a3f1c2e4b80012abcdef/categories?only_enabled=true" \
  -H "X-API-Key: ak_prod_YOUR_API_KEY"
```

### 3.5 Get Single Asset

Fetches the complete details and file blocks of a specific asset.

* **Method:** `GET`
* **Path:** `/api/v1/instance/{instanceId}/assets/{assetId}`
* **Required Scope:** `assets:read`
* **Query Parameters:** None
* **Request Body:** None

#### Response (`200 OK`)
Returns a single asset object (same schema as listed in [3.4 List Assets](#34-list-assets)).

#### Error Response
* `404 Not Found` if the asset does not exist or is not assigned to this instance.

#### cURL Example
```bash
curl -X GET "https://assets.yourcompany.com/api/v1/instance/6650a3f1c2e4b80012abcdef/assets/66c3d4e5f6a7b80012345678" \
  -H "X-API-Key: ak_prod_YOUR_API_KEY"
```

### 3.6 Track Asset View / Download Event

Atomically increments the asset's view or download counter in your app instance and logs an event for the analytics dashboard.

* **Method:** `POST`
* **Path:** `/api/v1/instance/{instanceId}/assets/{assetId}/track`
* **Required Scope:** `assets:read`
* **Headers:**
  - `X-API-Key: <YOUR_API_KEY>`
  - `Content-Type: application/json`
* **Query Parameters:** None

#### Request Body
```json
{
  "event": "view"
}
```

| Field | Type | Required | Allowed Values | When to Use |
| :--- | :--- | :--- | :--- | :--- |
| `event` | `string` | **Yes** | `"view"`, `"download"` | Use `"view"` when asset detail is opened/previewed. Use `"download"` when user exports, saves, or applies the asset. |

#### Response (`200 OK`)
Returns the updated counter totals after the increment:
```json
{
  "views": 451,
  "downloads": 82
}
```

> **Client Recommendation:** Execute this request asynchronously in the background ("fire-and-forget"). Do not block UI navigation waiting for this response.

#### cURL Example
```bash
curl -X POST "https://assets.yourcompany.com/api/v1/instance/6650a3f1c2e4b80012abcdef/assets/66c3d4e5f6a7b80012345678/track" \
  -H "X-API-Key: ak_prod_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"event": "download"}'
```

### 3.7 Global Search (Optional)

Searches across categories, subcategories, and assets matching a keyword.

* **Method:** `GET`
* **Path:** `/api/v1/search`
* **Required Scope:** `assets:read`

#### Query Parameters
| Parameter | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `q` | `string` | **Yes** | `""` | Search query keyword. |
| `limit` | `integer` | No | `6` | Maximum matches per entity type (1 to 50). |

* **Request Body:** None

#### Response (`200 OK`)
```json
{
  "categories": [ ... ],
  "subcategories": [ ... ],
  "assets": [ ... ]
}
```

#### cURL Example
```bash
curl -X GET "https://assets.yourcompany.com/api/v1/search?q=birthday&limit=10" \
  -H "X-API-Key: ak_prod_YOUR_API_KEY"
```

## 4. Common Error Codes

| Status Code | Reason | Resolution |
| :--- | :--- | :--- |
| **`401 Unauthorized`** | Missing or malformed `X-API-Key` header | Provide the valid API key in `X-API-Key` header. |
| **`403 Forbidden`** | Insufficient permissions or wrong instance | Check that the API key has `assets:read` / `categories:read` and is bound to `{instanceId}`. |
| **`404 Not Found`** | Asset or Instance does not exist | Verify the 24-character `{instanceId}` or `{assetId}`. |
| **`422 Unprocessable Entity`** | Validation failure | Inspect the request body (e.g. `event` must be either `"view"` or `"download"`). |
| **`429 Too Many Requests`** | Rate limit exceeded | Back off and retry requests after a delay. |
